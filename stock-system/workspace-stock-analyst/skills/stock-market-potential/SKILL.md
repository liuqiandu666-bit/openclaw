# 技能：市场潜力评估（大市场 · 高频 · 刚需）

## 角色设定

对已在深度调研中的股票，从**商业模式持久性**角度进行评分：  
目标市场够不够大（大市场）、客户使用够不够频繁（高频）、产品需求够不够刚性（刚需）。  
分别给出 **1年 / 3年 / 5年** 时间维度的展望评分，与 `stock-deep-analysis` 基本面评分并列呈现。

---

## ⚠️ 防幻觉铁律（最高优先级）

**每一个出现在报告中的市场规模数字，必须满足以下全部条件，否则写 `⚠️ 数据待核实`：**

1. 来自 web_search 的实际返回结果（不得使用训练记忆中的数字）
2. 能明确说出**来源机构名称**（如"艾瑞咨询2024年报告"）
3. 能明确说出**发布/更新时间**（年份，越近越好）

**以下行为严格禁止：**

- 说"预计市场规模约xxx亿"但没有来源 → 禁止
- 引用"据业内人士预测" → 禁止（必须有具名机构）
- 用训练数据中记忆的行业规模数字 → 禁止
- 搜不到权威数据时填写"估计"值 → 禁止，改写 `⚠️ 数据待核实`
- web_search 不可用时用行业常识、训练记忆或无来源网页概括来补评分 → 禁止

**高频/刚需维度**：不需要精确数字，可基于公司年报披露的业务模式、客户结构描述进行定性判断，但必须注明判断依据来自哪份文件。

## 数据来源优先级

按可信度从高到低：

### 第一优先：公司自身披露（最可信，有法律责任背书）

- 公司年报、招股说明书中引用的第三方市场数据（通常来自艾瑞、前瞻等机构）
- 公司投资者关系（IR）材料、业绩说明会文字记录
- 上交所/深交所公告中的行业背景描述

> 搜索方式：`web_search: "{公司名称} 年报 行业规模 市场空间"`  
> 或：`web_search: "{公司名称} 招股书 市场规模"`

### 第二优先：政府 / 监管机构官方数据

- 工信部、发改委、国家统计局、商务部发布的行业数据
- 行业主管部门（如中国证监会行业分类统计、国家卫健委医疗数据等）

> 搜索方式：`web_search: "工信部 OR 发改委 {行业名称} 规模 {年份}"`

### 第三优先：具名专业研究机构报告

仅接受以下机构（其他来源不予采信）：

- **国内**：艾瑞咨询、前瞻产业研究院、中商研究院、华经产业研究院、观研天下、灼识咨询
- **国际**：IDC、Gartner、Frost & Sullivan、麦肯锡、BCG（需确认有中文或正式英文报告）
- **券商研报**：中金、中信、华泰、国泰君安、海通等头部券商发布的行业深度报告

> 搜索方式：`web_search: "艾瑞 OR 前瞻产业 OR IDC {行业名称} 市场规模 2024 OR 2025"`  
> 搜索方式：`web_search: "{行业名称} 行业报告 市场规模 券商研报"`

### 第四优先：行业协会数据

- 中国XX协会、中国XX联合会等全国性行业协会年度统计
- 需注明协会全称和报告年份

### ❌ 不可采信来源（禁止引用）

- 百度百科、知乎、微信公众号文章、个人博客
- 来源不明的"据悉"、"业内预计"、"分析人士表示"
- 搜索结果摘要中无法追溯到原始机构的数字

## 三大评分维度定义

### 大市场（Market Size）

目标市场的天花板与当前渗透阶段。

| 分数 | 标准                                                           |
| ---- | -------------------------------------------------------------- |
| 9-10 | 万亿级以上 TAM，行业仍处成长早/中期，公司市占率 < 10% 有大空间 |
| 7-8  | 千亿级 TAM，或百亿级但公司占优势地位仍有扩张空间               |
| 5-6  | 百亿级且竞争激烈，增量空间有限，主要靠份额争夺                 |
| 3-4  | 小众细分市场（< 50亿），天花板明确                             |
| 1-2  | 夕阳行业或市场规模持续萎缩                                     |

> **无法获取权威 TAM 数据时**：写 `⚠️ 数据待核实`，大市场维度仅做定性描述，不打具体分数。

### 高频（Usage Frequency）

客户复购/续约/使用的频率，决定收入稳定性与客户粘性。

| 分数 | 标准                                                 |
| ---- | ---------------------------------------------------- |
| 9-10 | 每日使用型（日活产品：互联网服务、支付、消费刚需品） |
| 7-8  | 每月复购型（SaaS 订阅、食品饮料、工业耗材）          |
| 5-6  | 季度/半年采购（服装、3C、工程项目）                  |
| 3-4  | 年度采购（家电、汽车零部件、大宗合同）               |
| 1-2  | 数年一次（重大设备、基础设施建设）                   |

> **判断依据**：优先来自公司年报"主营业务"描述、客户结构披露、合同模式说明（框架合同 vs 一次性合同）。

### 刚需（Necessity）

客户是否必须购买此产品/服务，需求受经济周期影响程度。

| 分数 | 标准                                                             |
| ---- | ---------------------------------------------------------------- |
| 9-10 | 不可替代的基础性需求（基础工业原料、关键医疗、国防配套）         |
| 7-8  | 强刚需：客户核心业务依赖，切换成本高（核心工业软件、关键零部件） |
| 5-6  | 半刚需：改善型/升级型需求，经济下行可推迟但不可长期缺失          |
| 3-4  | 弱刚需：可选消费，周期性明显（娱乐、消费升级）                   |
| 1-2  | 完全可选：情绪消费、概念型产品，需求不稳定                       |

> **判断依据**：优先来自公司年报"经营风险"章节（公司自己描述需求周期性）、下游客户行业特征。

## 执行步骤

### 第零步：检查 web_search 就绪状态

```bash
python3 /home/<user>/.openclaw/workspace-stock-analyst/check_web_tools.py
```

若结果不是 `WEB_SEARCH_READY ...`，本技能直接进入“无法评估模板”，不要继续尝试 web_search，也不要用行业常识填充分数。
若任一 `web_search` 返回 `402`、`requires more credits`、`fewer max_tokens` 或类似额度错误，也直接进入“无法评估模板”，并注明“网络搜索额度不足”。
若结果是 `WEB_SEARCH_READY ...`，本技能至少要成功执行 1 次与行业/市场空间相关的 `web_search`；否则不得输出正常评分矩阵。

### 第一步：从公司年报/招股书提取（优先，最可信）

```
web_search: "{公司名称} 年报 2024 行业规模 市场空间"
web_search: "{公司名称} 投资者关系 行业分析"
web_search: "{公司股票代码} 招股说明书 市场规模"
```

> 目标：找到公司自己在年报中引用的市场规模数据及其来源机构。若公司年报有引用第三方数据，该数据视为第一优先级（公司有法律责任不得虚假陈述）。

### 第二步：补充权威机构数据（第二/三优先）

```
web_search: "艾瑞咨询 OR 前瞻产业研究院 {行业关键词} 市场规模 2024 OR 2025"
web_search: "工信部 OR 国家统计局 {行业关键词} 数据 {当前年份}"
web_search: "{行业名称} 行业研报 市场规模 中信 OR 华泰 OR 中金 2024"
```

> 每条搜索结果需确认：①来源机构名称明确 ②有发布时间 ③数字有具体单位（亿元/万亿）

### 第三步：核实高频/刚需判断依据

```
web_search: "{公司名称} 年报 主营业务 客户结构 合同模式"
web_search: "{公司名称} 业务模式 下游客户 复购"
```

> 高频/刚需不需要数字，但需要有文件依据。通常从年报"主营业务概述"或"行业分析"章节中提取。

### 第四步：交叉验证（关键数字需≥2个来源印证）

对于大市场维度的核心 TAM 数字：

- 若只有1个来源，在备注中标注"仅单一来源，参考意义有限"
- 若两个独立来源数字差异 > 50%，两个数字都列出，不取均值，说明口径差异原因

### 第五步：打分（依据必须可追溯）

评分表中的"具体依据"格式要求：

```
[数据内容] —— 来源：[机构名称]，[发布年份]
```

示例：

- ✅ `"2024年中国工业软件市场规模约2800亿元，预计2027年达5000亿——来源：前瞻产业研究院，2024年"`
- ✅ `"公司年报称主要收入为SaaS订阅模式，客户续约率超90%——来源：公司2023年年报"`
- ❌ `"据悉市场规模约xxx亿"` → 禁止
- ❌ `"行业普遍认为……"` → 禁止

## 趋势判断

根据三个时间节点的综合分变化，给出方向性判断：

- **上升型**：1年 < 3年 < 5年（市场持续扩张，商业模式增强）
- **稳定型**：三个节点分数相近（护城河稳固，无明显催化也无衰退风险）
- **峰值型**：1-3年高点，5年可能回落（政策红利窗口型、周期型）
- **衰退型**：5年综合分明显低于1年（技术替代风险、需求萎缩）

## 与 stock-deep-analysis 的关系

| 维度       | stock-deep-analysis     | stock-market-potential                    |
| ---------- | ----------------------- | ----------------------------------------- |
| 视角       | 当下基本面（财报数据）  | 未来商业潜力（市场结构）                  |
| 数据来源   | 本地数据库（财务三表）  | 公司年报 + 权威机构报告（via web_search） |
| 防幻觉手段 | 本地库强制查询          | 来源机构白名单 + 强制引用格式 + 交叉验证  |
| 时间维度   | 当前入场时机 + 估值预测 | 1/3/5年市场潜力变化                       |
| 评分       | 6维度综合 x.x/10        | 大市场/高频/刚需 × 3时间段                |

两项评分**并列展示**，共同构成该股票的完整投资价值判断。
